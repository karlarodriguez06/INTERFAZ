# Software FJ - Sistema de Gestión de Reservas
Proyecto desarrollado en Python para la gestión de clientes, servicios y reservas.

---
Autores:
- Omar Rafael de Arco Bolano
- Karla María Fuentes Rodríguez
---

## Descripción
El sistema permite:
- Registrar clientes
- Gestionar servicios
- Crear reservas
- Validar datos
- Manejar excepciones
- Registrar eventos y errores en logs
El proyecto fue desarrollado aplicando Programación Orientada a Objetos y manejo avanzado de excepciones.

---

## Tecnologías utilizadas
- Python
- Tkinter
- GitHub

---

## Interfaz gráfica
La aplicación cuenta con una interfaz gráfica desarrollada con Tkinter, permitiendo una interacción más dinámica y organizada con el usuario.

---

## Funcionalidades

- Registro de clientes  
- Creación de servicios  
- Gestión de reservas  
- Validación de datos  
- Manejo de errores
